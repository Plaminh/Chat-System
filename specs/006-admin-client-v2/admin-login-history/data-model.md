# Data Model: [A2] Admin Login History (Issue #8)

**Feature**: `specs/006-admin-client-v2/admin-login-history` | **Date**: 2026-11-24

## 1. Protocol Wire Entities (`common` Module)

All DTOs are immutable Java records defined in `com.chat.common`.

### 1.1 `LoginHistoryRequest` (`com.chat.common.dto.admin.LoginHistoryRequest`)
Sent by the client within `RequestEnvelope.payload` for `ActionType.ADMIN_LIST_LOGIN_HISTORY`.
- `userId`: `Long` (Nullable; `null` requests global history across all users. Must be positive if non-null)
- `sort`: `SortSpec` (Required; `field` must be `"loggedInAt"`, `direction` is `ASC` or `DESC`)
- `page`: `PageRequest` (Required; `page >= 0`, `1 <= size <= 100`)

### 1.2 `SortSpec` (`com.chat.common.dto.common.SortSpec`)
- `field`: `String` (Must match allowed repository sort field: `"loggedInAt"`)
- `direction`: `SortDirection` (`ASC` or `DESC`)

### 1.3 `PageRequest` (`com.chat.common.dto.common.PageRequest`)
- `page`: `int` (0-based page index, >= 0)
- `size`: `int` (Page size, 1..100)

### 1.4 `LoginHistoryEntry` (`com.chat.common.dto.admin.LoginHistoryEntry`)
Contained in the `items` list of `PageResult<LoginHistoryEntry>`.
- `loginHistoryId`: `long` (Database primary key, positive)
- `userId`: `long` (User ID, positive)
- `username`: `String` (Username, non-blank)
- `fullName`: `String` (Full display name, non-blank)
- `loggedInAt`: `OffsetDateTime` (Timestamp when login occurred, non-null)
- `loggedOutAt`: `OffsetDateTime` (Timestamp when session terminated, nullable; must not precede `loggedInAt`)

### 1.5 `PageResult<T>` (`com.chat.common.dto.common.PageResult`)
- `items`: `List<T>` (Page items)
- `page`: `int` (Current page index)
- `size`: `int` (Requested page size)
- `totalItems`: `long` (Total matching rows in database)
- `totalPages`: `int` (Total number of pages)

---

## 2. Server Persistence Models (`server` Module)

### 2.1 `LoginHistoryRecord` (`com.chat.server.model.LoginHistoryRecord`)
Model used by `LoginHistoryRepository` representing the joined SQL query result:
- `loginHistoryId`: `long`
- `userId`: `long`
- `username`: `String`
- `fullName`: `String`
- `loggedInAt`: `OffsetDateTime`
- `loggedOutAt`: `OffsetDateTime`

### 2.2 Database Schema (`login_history` Table)

```sql
CREATE TABLE login_history (
    login_history_id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id BIGINT NOT NULL,
    logged_in_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    logged_out_at TIMESTAMPTZ,
    CONSTRAINT fk_login_history_user
        FOREIGN KEY (user_id) REFERENCES users (user_id) ON DELETE CASCADE,
    CONSTRAINT chk_login_history_timestamps
        CHECK (logged_out_at IS NULL OR logged_out_at >= logged_in_at)
);

CREATE INDEX idx_login_history_user_time
    ON login_history (user_id, logged_in_at DESC);
CREATE INDEX idx_login_history_logged_in_at
    ON login_history (logged_in_at DESC);
```
